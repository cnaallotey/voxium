Create the Voxium GitHub App

Fills in the app manifest for you and sends it to GitHub. GitHub shows a confirmation page, then redirects to your Voxium site, which shows the one time code and the exact command to run.

Where you open Voxium in your browser. For local testing use http://localhost:3000.
GitHub must be able to reach it. For local testing put the tunnel URL here.
App names are unique on GitHub. Change it if "Voxium" is taken.
